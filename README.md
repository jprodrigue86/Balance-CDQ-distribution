# Balance CDQ — Distribution

Dépôt public de distribution uniquement.

Ce dépôt contient seulement les fichiers nécessaires à l'installation et aux mises à jour de Balance CDQ Android. Le code source de l'application est conservé dans un dépôt privé séparé.

L'accès à l'application reste contrôlé par la gestion des utilisateurs de Balance CDQ.
