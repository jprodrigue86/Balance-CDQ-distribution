# Balance CDQ V26.45

Ouverture automatique du compte CDQ enregistré sans NIP ni biométrie. Déployer le correctif serveur une fois dans Script Manager et installer Android 26.45 sans désinstaller.

Le serveur vérifie les utilisateurs et les rôles. Le contrôle Drive reste séparé. Un nouvel appareil nécessite un code d’activation à usage unique, ou la confirmation Google du créateur pour sa récupération. Ce package ne réimporte aucune donnée.
